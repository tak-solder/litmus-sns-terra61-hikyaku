# Build 27: Web: 検索画面

## やること

- 検索画面（`/search`）: キーワード入力と、結果の投稿一覧（新しい順、20件ずつ、無限スクロール。投稿カードは build-22 を再利用）。ゲストも使える
- 空・空白のみ、除外の語だけなど条件が成り立たない入力では検索せず、その旨を表示する（api の 400 の理由を表示）
- 検索が混み合ってタイムアウトした場合（503）は、その旨と再試行を促す表示を出す
- 検索語の語数・文字数に任意の上限を設けない（入力欄にも設けない）
- ヘッダーから検索画面へのリンク

## やらないこと

- ユーザー名での検索、投稿者や期間での絞り込み（スコープ外）
- 検索 API・負荷保護（build-21）

## 対応する受け入れ基準

- US-10.1, US-10.2, US-10.3, US-10.4, US-10.5, US-10.6, US-10.7, US-10.8, US-10.9, US-10.10

## 受け入れ基準

- [ ] キーワードで検索でき、結果が新しい順に20件ずつ表示され、続きが自動で読み込まれる
- [ ] 全角半角・大小の同一視、AND / 除外 / OR / フレーズが画面から使える
- [ ] 空・成り立たない入力では検索されず、その旨が表示される
- [ ] 503（タイムアウト）のときに案内が表示される
