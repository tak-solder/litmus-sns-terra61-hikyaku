# Build 23: Web: 投稿作成・単体ページ

## やること

- 投稿作成画面（`/posts/new`）: 本文（300文字以内の文字数表示）と画像1枚（JPEG / PNG / GIF / WebP、5MB 以内）の入力。理由つきのエラー表示（本文なし・301文字以上・2枚以上・形式外・5MB 超）。ゲストはログインを求められる。投稿後は自分のタイムラインの先頭に出る
- 単体ページ（`/posts/{id}`）: 本文・画像・投稿日時・投稿者名・合計いいね数・いいね済みの表示。権限が無い場合は 404。いいね／取り消し、自分の投稿なら削除。ゲストは is_liked_by_me が false
- シェア: 各一覧と単体ページのシェア操作で、単体ページの URL を発行する（URL のコピー、対応端末では Web Share API で他のアプリに渡す）
- 一覧の投稿カード（build-22）に、単体ページへのリンクとシェア操作を足す
- 単体ページの静的シェルと動的データの境界（急増時に毎回データを取得する構成）

## やらないこと

- 投稿者のユーザーページへのリンク（US-12.3 のうち移動の部分は build-24 で足す）
- ユーザーページ・フォロー（build-24）
- 投稿の編集（スコープ外）

## 対応する受け入れ基準

- US-4.1, US-4.2, US-4.3, US-4.4, US-4.5, US-4.6, US-4.7, US-5.1, US-5.2, US-7.1, US-7.2, US-7.3, US-7.4, US-7.5, US-12.1, US-12.2, US-12.3（いいね・取り消し・削除の部分）, US-12.4

## 受け入れ基準

- [ ] 本文だけ、画像だけ、両方のいずれでも投稿でき、不正な入力は理由つきで拒否される。ゲストは投稿できない
- [ ] 一覧の投稿から単体ページへ移動でき、単体ページに本文・画像・日時・投稿者名・合計いいね数・いいね済みが出る
- [ ] 単体ページと一覧からいいね／取り消しができ、自分の投稿にはいいねできない。自分の投稿は削除でき、削除後はどの画面にも出ない
- [ ] シェア操作で単体ページの URL がコピーまたは端末の共有機能に渡せる。シェアされた URL を開くと、権限のある人には表示され、非公開の投稿は本人とフォロワーだけが見られる
