# Build 08: Web: メール確認・パスワードリセット画面

## やること

- メールのリンク先になる確認結果画面（`/verify-email`）: トークンを api で確認し、成功・失敗を表示してログインへ誘導する
- パスワードリセット要求画面（`/password-reset`）: メールアドレスを入力して依頼する。結果の表示はアカウントの有無が分からない文言にする
- 新しいパスワード設定画面（`/password-reset/confirm`）: トークンと新しいパスワードを入力して設定し、ログインへ誘導する
- ログイン画面から要求画面へのリンク

## やらないこと

- 登録・ログイン画面（build-07）
- API の変更（build-03、05、06）

## 対応する受け入れ基準

- US-1.5, US-3.1, US-3.2

## 受け入れ基準

- [ ] 確認メールのリンクを開くと確認が完了した旨が表示され、ログインできるようになる。無効なトークンではエラーが表示される
- [ ] リセット要求画面からメールが送られ、リンクの画面で新しいパスワードを設定できる
- [ ] 設定後は新しいパスワードでログインでき、古いパスワードではログインできない
