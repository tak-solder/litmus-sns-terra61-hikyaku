# Build 25: Web: 公開範囲設定・フォロー申請一覧

## やること

- 公開範囲の設定画面（`/settings/visibility`）: 現在の設定（公開 / 非公開）を表示し、切り替える。非公開から公開への切り替えで未処理の申請が破棄される旨を、確認表示で伝える
- フォロー申請一覧画面（`/follow-requests`）: 自分宛ての未処理の申請を、申請者の名前つきで新しい順に20件ずつ、無限スクロールで表示し、承認・拒否ができる。処理した申請は一覧から消える
- ヘッダーから両画面へのリンク（ログインユーザーのみ）

## やらないこと

- フォロワー一覧（build-26）
- ユーザーページ（build-24）

## 対応する受け入れ基準

- US-11.1, US-11.5, US-13.1, US-13.2, US-13.3

## 受け入れ基準

- [ ] 現在の公開範囲が分かり、公開と非公開を切り替えられる
- [ ] 非公開から公開への切り替えで、未処理の申請が破棄される（一覧が空になる）
- [ ] 申請の一覧が申請者の名前つきで表示され、承認すると申請者がフォロワーになり、拒否すると申請が消える
- [ ] ゲストはこれらの画面を開けず、ログインを求められる

## 参照する設計ドキュメント
