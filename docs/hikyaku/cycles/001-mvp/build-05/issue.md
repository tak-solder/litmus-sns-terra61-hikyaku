# Build 05: 確認メール再送API

## やること

- `POST /api/auth/resend-verification`: 確認前のユーザーに確認メールを再送する。応答は、アカウントの有無や確認状態が分からない内容にする
- 再送へのレート制限の適用（IP とメールアドレスのハッシュ単位）。古い確認トークンは無効にする

## やらないこと

- 登録時の確認メール送信（build-03）
- Web の再送導線（build-07）

## 対応する受け入れ基準

- US-1.8

## 受け入れ基準

- [ ] 確認前のユーザーが再送を依頼すると、新しい確認メールが届き、古いトークンは使えなくなる
- [ ] 確認済み・未登録のメールアドレスでも応答が変わらない（メールは送られない）
- [ ] 連続した再送がレート制限で拒否される
