# Build 24: Web: ユーザーページとフォロー操作

## やること

- ユーザーページ（`/users/{id}`）: 名前、閲覧者が見られる投稿の一覧（新しい順、20件ずつ、無限スクロール。項目はフィードと同じ）、フォロー／フォロー解除／申請／申請取り消しのボタン。状態（フォロー済み・申請中）の表示。自分自身にはボタンを出さない。ゲストはページを閲覧できるが、フォローを求めるとログインへ誘導する
- 非公開ユーザーのページ: 投稿を見る権限が無い閲覧者にも、名前とフォロー（申請）ボタンを表示し、「投稿は非公開です」と分かる表示にする
- フォロー上限（5,000人）に達したときの理由表示
- 投稿者名からユーザーページへ移動できるリンクを、投稿カード（一覧）と単体ページに足す

## やらないこと

- フォロー中一覧、他ユーザーのフォロワー一覧（スコープ外）
- 公開範囲の設定・申請の承認（build-25）

## 受け入れ基準

- [ ] 投稿者名からユーザーページに移動でき、名前と閲覧可能な投稿の一覧（新しい順・続きの取得）が表示される
- [ ] 公開ユーザーはフォロー／解除でき、非公開ユーザーには申請になり申請中が分かる。申請中は取り消せる
- [ ] 自分自身にはボタンが出ない。ゲストはフォローできない
- [ ] 非公開ユーザーのページで、名前とボタンが表示され、投稿が非公開であることが分かる
- [ ] 上限に達したとき、その旨が表示される
