# Build 22: Web: トップ・グローバルフィード・タイムライン

## やること

- 画面は2つ: `/`（ログイン済みはタイムライン、ゲストはグローバルフィード）と `/global`（グローバルフィード）。ログインユーザーは、ヘッダーのタブで `/`（タイムライン）と `/global` を切り替えられ、どちらからも戻れる。ゲストにはユーザー登録とログインへの導線を出す
- 投稿カード（本文・画像・投稿日時（日本時間）・投稿者名・合計いいね数・いいね済みの表示）。画像は `<img src="/api/images/{id}">`（同一オリジンの cookie で認可される）。このビルドでは、カードに単体ページとユーザーページへのリンクを付けない（遷移先は build-23、24 で作り、そこでリンクを足す）
- 無限スクロール: 下までスクロールすると続きを自動で読み込む（Server Actions でカーソルを渡して取得）。20件ずつ
- PC とスマートフォンの幅に対応する。Next.js の静的シェル（`cacheComponents`）と動的データの境界を明確にする

## やらないこと

- 投稿作成・単体ページ・いいね・削除・シェア（build-23）
- ユーザーページ・フォロー（build-24）
- 検索（build-27）

## 受け入れ基準

- [ ] ゲストが `/` を開くとグローバルフィードが表示され、登録とログインへの導線がある。ログインユーザーが `/` を開くとタイムラインが表示される
- [ ] ログインユーザーは、`/` と `/global` をタブで行き来できる
- [ ] 一覧は新しい順で、各項目に本文・画像・投稿日時・投稿者名・合計いいね数・いいね済みが表示され、画像付きの投稿は画像も表示される
- [ ] 下までスクロールすると次の20件が自動で読み込まれ、末尾まで読むと終わりが分かる
- [ ] ゲストが（直接 URL で）タイムラインを開こうとするとログインを求められる
- [ ] スマートフォン幅と PC 幅で崩れない
