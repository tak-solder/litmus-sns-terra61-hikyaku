# Build 26: Web: フォロワー一覧

## やること

- フォロワー一覧画面（`/followers`）: 自分のフォロワーを名前つきで、フォロー成立日時の新しい順に20件ずつ、無限スクロールで表示する。各フォロワーを外す操作（確認つき）。外したフォロワーは一覧から消える
- ヘッダーからのリンク（ログインユーザーのみ）。ゲストはログインを求められる

## やらないこと

- 他ユーザーのフォロワー一覧、フォロー中一覧（スコープ外）
- 申請の承認・拒否（build-25）

## 対応する受け入れ基準

- US-14.1, US-14.2, US-14.3

## 受け入れ基準

- [ ] 自分のフォロワーが名前つきで新しい順に表示され、続きが自動で読み込まれる
- [ ] フォロワーを外すと一覧から消え、外された人は自分をフォローしていない状態になる
- [ ] 外された人は、改めて申請（自分が非公開）またはフォロー（公開）できる
